# 三水区理工学校综合高中部学生日常表现管理系统

这是可直接部署到 GitHub Pages 的 V1.1 静态网页版本。

## 目录结构

- `index.html`：网站入口，必须保留在仓库根目录
- `styles.css`：界面样式
- `app.js`：系统功能逻辑
- `学生导入模板.csv`：学生信息导入模板
- `.nojekyll`：告诉 GitHub Pages 按普通静态网站发布
- `.gitignore`：忽略本机无关文件
- `GITHUB部署教程.md`：从新建仓库到上线的完整操作说明

## 当前版本的数据方式

当前版本使用浏览器 `localStorage` 保存数据：

- 数据不会上传到 GitHub 仓库；
- 同一设备、同一浏览器下刷新网页后数据通常仍保留；
- 换电脑、换手机或换浏览器，不会自动同步；
- 清除浏览器网站数据可能导致本地数据丢失；
- 当前登录账号/密码写在前端代码中，不构成真正的服务器权限控制。

因此此版本适合原型演示、流程试用和界面验证。**不要把真实学生敏感数据当作正式多用户系统长期使用。** 正式校内部署应升级为 FastAPI + PostgreSQL 等服务器数据库架构。
